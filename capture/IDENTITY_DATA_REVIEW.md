# 챔피언 종류 식별 자료 정리 — 2026-10-29

원본 경기 `20261029_021213_de7fd0cb9fc9`의 저장 박스 277개를 모두 contact sheet로 시각 검수했다. 원본 파일/DB와 현재 위치 탐지 모델, 런타임 참조는 수정하지 않았다.

## 결과

- 277개 중 35개는 UI/비유닛/심한 조각으로 제외, 추가 55개는 가림·불완전한 몸체·다른 물체 혼합으로 종류 학습에서 제외: 합계 90개.
- 기존 사용자 확인 이미지와 시각적으로 연결한 새 이미지 47개. 이전 16개 참조와 합쳐 16개 ID / 63개 이미지.
- 나머지 사용 가능 후보 140개는 이름 미확정 40개 시각 그룹으로 정리. 그룹은 서로 다른 챔피언 수를 의미하지 않는다. 스킨/별/자세 차이로 같은 종류가 다른 그룹일 수 있다.
- 제외된 파일은 삭제하지 않았다. 이미지별 제외/보류 이유, 원본 박스, 시각 그룹, 연결 근거를 manifest.json에 보존했다.
- 새 47개는 사용자가 각각 확인한 라벨이 아니라 기존 사용자 확인 참조에 대한 assistant 시각 매칭이다. provenance에 이 차이를 기록했다.

## 위치

`capture/dataset/set18/identity-curated/`:

- manifest.json: 전체 277개 검수 결과.
- confirmed.json, confirmed/: 63개 참조/연결 이미지, championId 및 경기 ID.
- questions.json: 1~40 번호, 대표 이미지 및 시각 그룹 연결.

동일 파일은 해시로 제거했지만 인접 라운드의 유사한 자세는 여전히 포함돼 있다. 이미지 개수를 독립 표본 수로 해석하지 않는다. 제공된 과거 확인 라벨은 보존하고 새 연결은 별도 데이터로 내보냈다.

## 학습 상태

종류별 정답 이름이 미확정이므로 분류 모델 학습은 아직 시작하지 않았다. 확인된 16종 중 조약돌·케일·바루스·코부코는 각각 한 장뿐이다. 임의의 같은 경기 프레임을 train/val로 나눠 정확도를 부풀리지 않으며, 원본 경기 ID를 유지한다. 이름 확인 후 catalog ID와 연결하고, 클래스별 샘플/경기 수를 다시 확인해 실험 가능한 범위를 정한다. 현재 위치 탐지 ONNX와 이름 분류는 별도 작업이다.

이번에는 새 원본 경기 전체에 종류 학습 후보를 추출/검수했을 뿐, ‘모든 챔피언 확보 완료’나 종류 식별 정확도를 확인한 것이 아니다.

## 40개 이름 확인 반영 (2026-10-29)

사용자가 1~40 전체 번호의 이름을 제공했다. questions.json의 40개 번호를 현재 Set 18 catalog의 고유 ID와 연결했다. 대표 이미지는 user_confirmed, 같은 시각 묶음으로 전파한 다른 이미지는 visually_grouped_to_user_confirmed_representative로 출처를 구분했다. 기존 제외/잘림 상태는 유지했다. 원본 라벨의 수정 전 사본을 *.before-40-labels에 보존했다.

현재 56종 / 203개 이미지이며 미확인 대표 그룹은 0개다. 각 종류별 이미지·경기 수는 identity-curated/coverage.json 및 class-counts.csv에 있다. 12종은 이미지 한 장, 44종은 한 경기뿐이며 12종만 두 경기에서 확보됐다. 이전 문단의 '40개 이름 확인 대기'와 63개 집계는 이번 갱신 전 기록이다.

catalog의 기본 항목 중 현재 정리된 라벨에 아직 없는 것은 렉사이, 요릭, 아칼리, 아무무, 아펠리오스, 아이번, 장로 드래곤, 카르마, 마스터 이다. 이는 플레이하지 않았다는 의미가 아니라 사용 가능한 이름 라벨 이미지가 없다는 의미다. 심하게 잘려 제외한 이미지와 다른 별도 캡처에서 추가 확보 가능 여부를 확인해야 한다. 럭스는 사용자가 형태를 지정하지 않아 canonical Lux ID로 묶고 형태 인식은 미확정으로 기록했다.

이번 갱신은 라벨/자료 수 집계이며 종류 분류 모델 학습이나 정확도 검증을 수행한 것은 아니다. 단일 경기 이미지의 무작위 분할로 검증률을 만들지 않았고, 런타임 모델과 참조를 자동 교체하지 않았다. 모든 종류를 검증하려면 종류별 다른 경기 자료가 필요하다. 현 자료로 제한된 실험을 하더라도 한 장뿐인 종류의 일반화 성능은 확인할 수 없다.
