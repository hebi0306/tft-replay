# 65종 종류 인식: 특징점 보완

## 변경

기존 픽셀 비교가 미확인으로 끝날 때만 몸체 내부의 SIFT 특징점과 상대 배치로 다시 확인합니다. 새 라이브러리/다운로드/신경망 학습은 사용하지 않습니다. 128×128 몸체의 상단/가장자리를 제외하고 최대 160개 특징점을 사용합니다. 후보와 1:1 대응을 이루는 특징점이 8개 이상, 기하학적 일치율 80% 이상, 배율 0.6~1.6 범위, 충분한 공간 분포, 다음 종류 대비 3개 이상 차이를 모두 만족해야 확정합니다. 기존 픽셀 임계값 .85/.15는 유지합니다.

원래 `confidence`는 후보의 픽셀 유사도로 유지하고, 기하학적 결과는 `identityMethod=body-feature-geometry`, `identityInliers`로 별도 저장합니다. 인라이어 수를 확률처럼 변환하지 않습니다. 유닛 탐지가 없는 벤치 슬롯에는 이 판정 근거도 남기지 않습니다. 아이템/성급의 인식 방식은 바꾸지 않았습니다.

## 검증

- 같은 경기의 참조를 모두 제외: 다른 경기에 참조가 있는 96개 중 확정 정답 21→35, 미확인 61, 오답 0. 참조가 없는 종류 145개 모두 거부.
- 모루/구슬/배경 17개 모두 거부.
- 밝기/노이즈 합성 변형 723개 비교: 정답 63→107, 오답 0→0, 미확인 660→616.
- 자기 참조 연결 검사: 65종 모두 자신의 참조를 올바른 이름으로 반환. 이는 독립적인 정확도 검사가 아님.
- 회귀 테스트 44개 통과. 회전/배율 변화 시 특징점 판별, 유사 후보 동점 거부, 빈 이미지 거부 포함.
- 기존 Stage/HP/Gold/Level/스크린샷 저장·조회 검사 통과.
- 기존 51라운드 재분석 완료. 이름 반환 302/미확인 149는 참조를 만든 원본 경기가 포함된 기능 검사 수치이며 정확도가 아님. 원본 DB 해시 유지 확인.
- 비교당 평균 약 33.4ms. 기존 23.3ms보다 증가. 캡처 UI 스레드에서 별도로 실행하는 기존 구조 유지.

## 한계

현재 적은 기존 자료를 방법 선택과 검증에 반복 사용했습니다. 오답 0은 이 작은 자료 안의 관측이며 향후 오답이 없다는 보장이 아닙니다. 상당수 종류는 한 경기에만 참조가 있으므로 65종 전체의 경기 간 정확도를 계산할 수 없습니다. 새로운 자세/가림/해상도에서 65종 안정 인식이 완료된 상태가 아닙니다. 특징점이 부족하거나 배경 효과가 강한 경우 미확인을 유지합니다.
